# Splash Arena 🌊🔫

Подводный шутер от первого лица на **Godot 4.6** + **Photon Fusion 3**
(топология **Client-Server**, GDScript). Синхронизация через **GitHub**.

> Статус: **каркас проекта** — сеть, игрок-дайвер, подводная арена и вода-заглушка.
> Дальше по шагам добавляем геймплей: оружие, урон, команды, а затем красивую воду.

---

## 1. Что нужно установить (у тебя на Windows)

| Что | Зачем | Где взять |
|---|---|---|
| **Godot 4.7.x** (стандартный, не .NET) | движок | https://godotengine.org/download |
| **Fusion Godot SDK 3.0.0 Preview** (сборка под Godot 4.6+, работает и на 4.7) | сеть Fusion 3 | в редакторе: **AssetLib → Photon Fusion** (или с сайта Photon, см. ссылку ниже) |
| **Аккаунт Photon + Fusion App** | сетевой доступ (бесплатный план) | https://dashboard.photonengine.com |

> Файлы Fusion-плагина (папку `addons/fusion/`) клади **вручную** — она в `.gitignore`,
> чтобы бинарники не лежали в git. CI ставит её сам при проверке.

**Прямые ссылки Photon (SDK и доки):**
- Скачать SDK: https://doc.photonengine.com/fusion-godot/v3-client-server/getting-started/sdk-download
- Клиент-сервер quick start: https://doc.photonengine.com/fusion-godot/v3-client-server/getting-started/quick-start-guide

## 2. Первый запуск — по шагам

1. Склонируй репозиторий (или открой его в Godot).
2. Открой проект в Godot 4.7 — редактор создаст `.godot/` сам.
3. Поставь плагин Fusion:
   - **AssetLib → ищи `Photon Fusion` → Download → Install**, либо
   - скачай SDK с сайта Photon и скопируй папку `fusion/` в `addons/`.
4. Настрой секретный конфиг:
   - скопируй `config/secret.example.cfg` → `config/secret.cfg`;
   - вставь в `secret.cfg` свой **Fusion App ID** (Photon Dashboard).
5. Запусти проект (F5). Если всё ок — увидишь подводную арену из-под воды.

> ⚠️ `config/secret.cfg` и `addons/fusion/` в `.gitignore` — секреты и бинарники
> в GitHub **не попадут**. Идеально для командной работы.

---

## 3. Тест сети (2 игрока на одном ПК)

1. В Godot: **Debug → Customize Run Instances → Enable Multiple Instances = 2**.
2. Нажми Play. Первый инстанс создаёт комнату → он сервер (master), спавнит себя.
3. Второй инстанс подключается клиентом → просит сервер заспавнить его.
4. Управление: **WASD** — плыть, **Space** — вверх, **Ctrl** — вниз, **мышь** — осмотреться.
5. Оба окна видят друг друга и двигаются синхронно (сервер авторитетен).

> Если не работает — смотри вкладку **Output** (лог Fusion) и раздел «FAQ» ниже.

## 4. Архитектура и структура проекта

**Топология — Client-Server (dedicated/player-hosted):**
Кто создал комнату → **master client** = сервер симуляции. Он решает, что происходит
в мире. Клиенты шлют свой **ввод** (input queue) → сервер исполняет его авторитетно →
состояние реплицируется всем. Клиент с input-authority дополнительно **предсказывает**
своё движение (плавно, без лага), а при расхождении получает коррекцию.

```
scenes/
  main/main.tscn           # главная сцена: свет, вода, арена, менеджер матча
                             # (+ PreviewCamera: вид на арену, пока твой дайвер не заспавнился)
  player/player.tscn       # дайвер: CharacterBody3D + FusionServerReplicator + камера
  ui/main_menu.tscn        # стартовое меню (запуск игры)
scripts/
  main/match_manager.gd    # сеть: вход в комнату, спавн по Client-Server схеме
  player/player.gd         # движение/осмотр (FPS), упаковка ввода, предсказание
  world/arena.gd           # процедурная арена-пещера (стены, дно, укрытия)
  world/underwater_light.gd# подводный свет + туман
  ui/main_menu.gd          # логика меню
shaders/
  water/surface.gdshader   # ВОДА v0.1: заглушка (см. шаг «Вода»)
autoload/
  app_config.gd            # читает config/secret.cfg (App ID)
  inputs.gd                # регистрирует клавиши (WASD + Space/Ctrl)
config/
  secret.example.cfg       # шаблон для секретного конфига
addons/fusion/             # ⛔ НЕ в git — ставится вручную / через CI
```

**Ключевые сетевые примитивы Fusion в этом каркасе:**

| Узел / вызов | Роль |
|---|---|
| `FusionSpawner` | фабрика сетевых объектов (спавнит `player.tscn`) |
| `FusionServerReplicator` | репликация в Client-Server: позиция, поворот, свойства, ввод |
| `replicator.on_process_input` | сигнал: исполнение ввода (сервер / предсказание) |
| `replicator.queue_input(...)` | клиент отправляет ввод на сервер |
| `replicator.process_input_queue()` | прогон очереди ввода (вызывается каждый physics tick) |
| `replicator.set_input_authority(id)` | кому принадлежит ввод (сервер спавнит под игрока) |
| `Fusion.join_or_create_room()` | создаёт/ищет комнату; создатель = master client |
| `Fusion.rpc(...)` / `@rpc("any_peer", ...)` | запрос спавна от клиента к серверу |

## 6. FAQ и грабли

**`config/secret.cfg` не найден / App ID пуст** → скопируй шаблон и вставь ID (шаг 2.4).

**Fusion не загружается / ошибки GDExtension** → проверь, что папка `addons/fusion/`
на месте и что установлен именно **Godot 4.7.x** (SDK собран под 4.6, работает на 4.6+).

**Не видно второго игрока / нет соединения** → запусти 2 инстанса (раздел 3);
убедись, что Photon-аккаунт активирован и App ID верный.

**Я на Windows, а CI (Linux) ругается на Fusion** → CI использует зеркало SDK
(переменная `FUSION_7Z_URL` в secrets/vars репозитория). Как настроить — ниже.

## 7. CI: авто-проверка проекта (GitHub Actions)

В `.github/workflows/ci.yml` (**в корне репозитория**) при каждом пуше Godot 4.7 headless
импортирует проект и проверяет, что он открывается без ошибок. Fusion SDK CI ставит сам:
по умолчанию качается публичное превью с сайта Photon, а если хочешь зафиксировать
конкретную сборку — задай свой URL зеркала:

1. На GitHub: **Settings → Secrets and variables → Actions**.
2. Добавь переменную `FUSION_7Z_URL` (или секрет с тем же именем) — прямую ссылку
   на архив Fusion SDK (например `https://downloads.photonengine.com/download/fusion-godot/...7z?pre=sp`).
   CI скачает его на раннер и положит в `Splash-Arena/addons/fusion/` перед проверкой.
3. Запушь — увидишь галочку CI в PR.

> Без переменной CI просто возьмёт публичное превью — проверка всё равно сработает.
> Сам код проекта проверяется и без сети Fusion: скрипты и сцены обязаны открываться чисто.
